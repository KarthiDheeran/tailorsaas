4A. Order Creation — Detailed Walkthrough

புதிய order create செய்யும் போது இந்த sequence follow செய்தால் mistakes குறையும்.

Full Order Entry Flow

  1. Customer Select: முதலில் customer phone/name search செய்யவும்.
  2. Customer கிடைக்கவில்லை என்றால் Create New Customer மூலம் உடனே add செய்யவும்.
  3. Order Details: Men/Women/section அல்லது type code சரியா இருக்கிறதா check செய்யவும்.
  4. Garment Type: Half Shirt, Pant, Chudidar போன்ற garment select செய்யவும்.
  5. Measurement Window: garment select செய்ததும் measurement entry screen open ஆகும்.
  6. Body Measurements: tailor-க்கு தேவையான அளவுகள் enter செய்யவும்.
  7. Work Details / Add-ons: lining, shawl, pocket, button போன்ற extra work இருந்தால் select செய்யவும்.
  8. Quantity: கீழே உள்ள Quantity field-ல் required qty enter செய்யவும்.
  9. Save Item Details: இந்த button click செய்தால் item order list-க்கு add ஆகும்.
  10. More garments இருந்தால் மீண்டும் Garment Type select செய்து same steps repeat செய்யவும்.
  11. Payment: Advance amount மற்றும் payment mode select செய்யவும்.
  12. Save Order: final save செய்த பிறகு தான் order number confirm ஆகும்.

Before Save Checklist

  1. Customer name/mobile correct-aa?
  2. Delivery date correct-aa?
  3. All garments added-aa?
  4. Qty correct-aa?
  5. Measurements entered-aa?
  6. Add-ons / Work Details amount correct-aa?
  7. Total, Paid, Balance correct-aa?

Customer Training Note

“Save Item Details” என்பது single garment save செய்யும் button. “Save Order” என்பது முழு order-ஐ final save செய்யும் button. இதை customer-க்கு clearly explain செய்யவும்.

Common Mistakes

Garment select செய்துவிட்டு measurement save செய்யாமல் order save செய்தால் item list empty ஆகலாம். அதனால் முதலில் item list-ல் garment visible இருக்கிறதா check செய்ய வேண்டும்.

Job Cards Detailed FlowTailorSaaS Training

8A. Job Cards — Detailed Walkthrough

Production tracking மற்றும் staff salary calculation புரிய இந்த flow customer-க்கு முக்கியம்.

1) Production Print

  1. Job Cards → Production Print open செய்யவும்.
  2. Order section / from no / to no / date filter மூலம் print செய்ய வேண்டிய orders select செய்யவும்.
  3. Select filtered click செய்தால் matching orders select ஆகும்.
  4. Print Production Bundle click செய்து slips print செய்யவும்.
  5. Each garment qty அடிப்படையில் Cutting/Stitching slip generate ஆகும்.

2) Tally Scan

  1. Job Cards → Tally Scans open செய்யவும்.
  2. Staff member select செய்து lock செய்யவும்.
  3. Tailor completed slip barcode scan செய்யவும்.
  4. Scan success ஆனதும் staff payable/salary record update ஆகும்.
  5. Tally scan delivery flow-ஐ stop செய்யாது; இது mainly salary tracking.

3) Order Ready

  1. Job Cards → Order Ready open செய்யவும்.
  2. Order list-ல் each order one row ஆக show ஆகும்.
  3. Customer physically delivery-க்கு ready என்றால் Mark Order Ready click செய்யவும்.
  4. Cover/Bin location optional-aa enter செய்யலாம்.
  5. Ready mark ஆன order Delivery page-ல் show ஆகும்.

Important Explanation

Customer shop workflow-ல் tailor slips daily/night/weekly scan செய்யலாம். ஆனால் item physically ready என்றால் Order Ready mark செய்யலாம். Ready status என்பது customer delivery-க்கு தயாராக உள்ளது என்பதைக் குறிக்கும்.

Status Meaning

Not Ready: இன்னும் customer delivery-க்கு தயாராக இல்லை.
Ready: delivery desk-ல் handover செய்ய தயாராக உள்ளது.
Delivered: customer-க்கு கொடுக்கப்பட்டது.

Quick access

Keyboard Shortcuts

Mouse குறைவு, வேகம் அதிகம்

Shortcut Screen / Action எப்போது பயன்படுத்த வேண்டும்
F2 New Order புதிய customer order உருவாக்க, garment items, measurements, photos, advance amount, delivery date சேர்த்து save செய்ய பயன்படுத்தவும்.
F3 Delivery Customer receipt scan/search செய்து, balance amount collect செய்து, ready order-ஐ delivered ஆக mark செய்ய பயன்படுத்தவும்.
F4 Tally Scans Tailor/staff முடித்த job card scan செய்து salary payable பதிவு செய்ய பயன்படுத்தவும். Daily use-க்கு Quick Scan; special case-க்கு Partial / Extra.
F5 Order Ready Order-ல் உள்ள அனைத்து garments ready ஆன பிறகு, அந்த full customer order-ஐ Ready ஆக mark செய்ய பயன்படுத்தவும்.
F6 Production Print Cutting/Stitching production slips print செய்ய பயன்படுத்தவும். Garment group, order number, date போன்ற filters மூலம் selected work மட்டும் print செய்யலாம்.
Ctrl + K Scan / Find App-ல் எந்த screen-லிருந்தும் order number, customer, phone, barcode போன்றவற்றை வேகமாக search செய்ய பயன்படுத்தவும்.
Alt + N New Order button Dashboard/header-ல் இருந்து mouse இல்லாமல் new order page open செய்ய பயன்படும்.
Alt + S Save Order Order details அல்லது edit order முடித்த பிறகு mouse இல்லாமல் save செய்ய பயன்படும்.

Tip: Barcode scan செய்யும்போது ஒரு scan success/failure status வந்த பிறகே அடுத்த barcode scan செய்யவும்.

Daily workflow

Main Screens Explained

Customer training guide

Dashboard

இன்றைய production summary, pending stage counts, due orders, முக்கிய alerts ஆகியவை தெரியும். Shop owner daily overview பார்க்கும் screen.

Orders > New Order

Customer, garment, measurements, add-ons/work details, photos, amount, delivery date சேர்த்து புதிய order உருவாக்கும் main screen.

Orders > View Order

Existing orders search/view/edit செய்ய, receipt print செய்ய, payment மற்றும் order follow-up பார்க்க பயன்படும்.

Job Cards > Tally Scans

Tailor/staff முடித்த work cards scan செய்து staff salary payable பதிவு செய்யும் screen. Quick Scan daily use; Partial / Extra special use.

Job Cards > Order Ready

Order-ல் பல garments இருந்தாலும் customerக்கு ஒரு order row மட்டும் காட்டி, full order ready ஆனதும் Ready ஆக mark செய்ய பயன்படும்.

Job Cards > Production Print

Cutting மற்றும் Stitching production/job slips print செய்ய பயன்படும். Shirt/Pant/common group அல்லது specific order filter செய்து print செய்யலாம்.

Delivery

Customer garments collect செய்ய வரும் போது receipt scan/search செய்து, full/partial amount collect செய்து delivered ஆக mark செய்யும் screen.

Customers

Customer details add/search/view செய்யவும், saved measurements பார்க்கவும் பயன்படும். Repeat customer order வேகமாக create செய்ய உதவும்.

Finance

Income, pending dues, adjustments, expenses, payment tracking பார்க்க பயன்படும். Owner collection மற்றும் balance check செய்யலாம்.

Inventory

Inventory enabled இருந்தால் fabric/material stock மற்றும் usage maintain செய்ய பயன்படும்.

Staff

Staff/tailor details, rates, payable, payment/advance records maintain செய்யும் payroll control screen.

Reports

Orders, payments, pending dues, production details போன்ற reports பார்க்க பயன்படும். Business performance review செய்ய உதவும்.

Settings

Catalog, garment types, fields, add-ons, users, roles, billing, shop configuration manage செய்யும் admin screen.

Quick access

Keyboard Shortcuts

Use keyboard, reduce mouse work

Shortcut Screen / Action How the customer should use it
F2 New Order Create a new customer order, add garment items, measurements, photos, advance amount, and save. Use this when the customer gives a new tailoring order.
F3 Delivery Scan/search the customer receipt, collect pending balance if needed, and mark the ready order as delivered. Use this at the delivery counter.
F4 Tally Scans Scan returned job cards to record tailor/staff completed work and salary payable. Daily scans use Quick Scan; Partial / Extra is for special monthly or manual entries.
F5 Order Ready View pending orders and mark the full customer order as Ready when all garments are ready for delivery. This does not wait for salary/tally scan completion.
F6 Production Print Print cutting/stitching production slips for filtered orders or all listed orders. Use filters like garment group, order number, or date when printing selected work.
Ctrl + K Scan / Find Quickly search order number, customer, phone, or barcode from anywhere in the app. Use this when you want to jump to a record fast.
Alt + N New Order button Opens the new order page from dashboard/header where available. Useful for keyboard-first order entry.
Alt + S Save Order Saves the current order screen without using the mouse. Use after completing order details or editing an order.

Tip: For fast barcode work, scan one barcode and wait for success/failure status before scanning the next barcode.

Daily workflow

Main Screens Explained

Two-line customer guide

Dashboard

Shows production summary, pending stage counts, due orders, and important business alerts. Use this as the shop owner’s daily overview screen.

Orders > New Order

Create a new order with customer, garment, measurements, add-ons/work details, photos, amount, and delivery date. This is the main billing/order-entry screen.

Orders > View Order

Search, view, edit, print receipt, check payment, and follow up existing orders. Staff can confirm order details after creation.

Job Cards > Tally Scans

Used mainly for staff salary records after tailor/staff returns completed work cards. Quick Scan is for daily use; Partial / Extra is used only when needed.

Job Cards > Order Ready

Mark one full customer order as ready for delivery. Even if multiple garments are inside the order, the customer sees one order row.

Job Cards > Production Print

Print production/job slips for cutting and stitching. Filters can be used for Shirt/Pant/common groups or specific orders before printing.

Delivery

Use when the customer comes to collect garments. Staff can scan/search receipt, collect full or partial amount, and mark the order delivered.

Customers

Add, search, and view customer details and saved measurements. This helps repeat customers avoid re-entering all measurements.

Finance

Check income, pending dues, adjustments, expenses, and payment tracking. Shop owner can review money collected and balances.

Inventory

Maintain stock/material details when inventory is enabled. It helps track fabric/material movement and usage.

Staff

Maintain staff/tailor records, rates, payable details, and payment/advance records. This is the payroll control area.

Reports

Check reports such as orders, payments, pending dues, and production information. This helps the owner review shop performance.

Settings

Manage catalog, garment types, fields, add-ons, users, roles, billing, and shop configuration. Only admin/owner should change these settings.
